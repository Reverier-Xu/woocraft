# woocraft

A GPU-accelerated graphical component library for Rust, built on
[GPUI](https://github.com/zed-industries/zed).

> this repository is a full rewrite of the previously published `woocraft`
> crates. the version line restarts at `0.6.0`.

## status

the workspace is live on gpui `0.2` from crates.io (publishable, unlike the
old zed git dependency). the component surface grows back under
`crates/woocraft` module by module.
